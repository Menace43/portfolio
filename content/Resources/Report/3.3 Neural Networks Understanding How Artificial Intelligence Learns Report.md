## 1. Introduction

## 3. What Is a Neural Network?

A neural network is a machine-learning model consisting of interconnected computational units arranged into layers. The network receives input data, processes that information through one or more layers, and produces an output or prediction.

The fundamental building block is the artificial neuron. A neuron receives one or more numerical inputs, assigns different levels of importance to those inputs through weights, adds a bias, and then applies an activation function. The resulting value is passed to another neuron or to the output layer.

A simplified representation is:

**Inputs → Weighted Calculations → Activation Function → Output**

The network becomes more powerful when many neurons are connected together. Multiple layers allow the model to transform information progressively and recognize increasingly complex relationships. IBM describes the standard structure as consisting of an input layer, hidden layers, and an output layer.

## 4. Components of a Neural Network

### 4.1 Input Layer

The input layer receives the information provided to the model. The inputs depend on the problem being solved.

For example, a model designed to predict whether a customer may cancel a service could receive inputs such as:

- Customer tenure
- Number of support requests
- Monthly cost
- Usage frequency
- Previous cancellations or complaints

For image recognition, the inputs could represent numerical information derived from image pixels.

The input layer therefore represents the information that the model needs to analyze.

### 4.2 Neurons

Neurons are computational units that process information. Each neuron receives values from previous neurons, applies weights and a bias, and produces an output.

A simplified neuron can be represented as:

**z = (x₁w₁ + x₂w₂ + ... + xₙwₙ) + b**

where:

- **x** represents an input.
- **w** represents the weight associated with that input.
- **b** represents the bias.
- **z** represents the weighted combination before activation.

The neuron then applies an activation function to this value.

### 4.3 Weights

Weights determine how strongly individual inputs influence a neuron's calculation. During training, the neural network changes these values so that its predictions become more accurate.

For example, if a model is learning to identify spam emails, certain words or characteristics may become more influential than others. The corresponding weights allow the model to represent these differences in importance.

### 4.4 Biases

A bias is an additional parameter that helps a neuron adjust its output. It provides flexibility by shifting the point at which the neuron responds.

Weights and biases are learned parameters. Adjusting them is a central part of neural-network training.

### 4.5 Activation Functions

An activation function transforms the neuron's weighted input into an output. Activation functions introduce nonlinearity, which allows neural networks to learn relationships that cannot be represented effectively using only simple linear calculations.

Common activation functions include:

- **ReLU (Rectified Linear Unit)**
- **Sigmoid**
- **Tanh**
- **Softmax**, commonly used when producing probabilities across multiple classes

IBM identifies activation functions such as ReLU, sigmoid, and tanh as important components of neural-network computation.

## 5. Neural Network Architecture

A basic neural network can be visualized as a sequence of layers:

**Input Layer → Hidden Layer 1 → Hidden Layer 2 → Output Layer**

### Input Layer

Receives the original features.

### Hidden Layers

Transform the information and identify patterns. A network may contain one hidden layer or many hidden layers.

### Output Layer

Produces the final result. Depending on the task, this could be a classification, probability, numerical prediction, or other output.

For example, a simple image-classification system might receive numerical image features as input, process those features through several hidden layers, and produce probabilities representing possible categories.

## 6. How Neural Networks Learn

A neural network does not automatically know the correct answer when it is first created. It learns through training.

The training process can be understood as a repeated cycle.

### Step 1: Forward Propagation

Training data is provided to the network. Information moves from the input layer through the hidden layers toward the output layer.

The network generates a prediction based on its current weights and biases.

### Step 2: Error Calculation

The prediction is compared with the correct answer, or target.

A loss function measures how different the prediction is from the desired result. A larger error indicates that the model needs greater adjustment.

### Step 3: Backpropagation

The error is propagated backward through the network. The model calculates how much different weights and biases contributed to the error.

This process allows the network to determine how its internal parameters should change.

### Step 4: Weight Adjustment

An optimization method such as gradient descent adjusts the weights and biases to reduce the loss.

This cycle is repeated across many training examples. Over time, the model attempts to find parameter values that produce increasingly accurate predictions. IBM describes this training sequence as forward pass, error calculation, backpropagation, and weight updating.


## 7. Backpropagation and Gradient Descent

Backpropagation is one of the most important concepts for understanding neural-network training.

During a forward pass, the model makes a prediction. After the error is calculated, backpropagation works backward through the network to determine how the parameters contributed to the error.

Gradient descent then provides a method for adjusting the parameters in a direction that reduces the loss.

An easy way to visualize gradient descent is to imagine a person walking down a mountain while trying to reach the lowest point. The "height" represents the model's loss, and each adjustment attempts to move toward a lower value.

The process can be summarized as:

**Predict → Measure Error → Calculate Gradients → Update Parameters → Predict Again**

IBM explains that backpropagation and gradient descent work together to progressively reduce prediction error during training.

## 8. Types of Neural Networks

Neural networks have developed into different architectures designed for different types of problems.

### 8.1 Feedforward Neural Networks

In a basic feedforward network, information moves from the input layer through hidden layers to the output layer.

These networks provide a foundation for understanding more advanced architectures.

### 8.2 Convolutional Neural Networks

Convolutional neural networks, or CNNs, are particularly useful for image and other grid-like data. They can identify spatial patterns and are widely associated with computer-vision tasks.

Applications include:

- Image classification
    
- Object recognition
    
- Medical-image analysis
    
- Facial recognition
    
- Visual inspection
    

### 8.3 Recurrent Neural Networks

Recurrent neural networks, or RNNs, are designed for sequential data. They incorporate information from previous steps and have historically been used for tasks such as speech recognition and time-series analysis.

### 8.4 Transformers

Transformers are a modern neural-network architecture that uses attention mechanisms to model relationships within data. They have become especially important in natural language processing and are foundational to many modern language models.

IBM identifies CNNs, RNNs, and transformers as major neural-network architectures with different strengths and applications.

## 10. Advantages of Neural Networks

Neural networks provide several important advantages.

### Ability to Learn Complex Patterns

Neural networks can learn nonlinear relationships that may be difficult to model using simpler algorithms.

### Adaptability

When trained with appropriate data, neural networks can learn patterns without requiring every decision rule to be manually programmed.

### Broad Application

The same fundamental concepts can support applications involving images, text, speech, numerical data, and sequences.

### Scalability

Large neural networks can contain millions or even billions of parameters and can be trained on very large datasets.

## 11. Limitations and Challenges

Neural networks also present important challenges.

### Data Requirements

Effective neural networks often require substantial amounts of high-quality training data.

### Computational Requirements

Larger models can require significant computing resources for training and deployment.

### Interpretability

Some neural networks can be difficult to interpret because their predictions result from many interconnected parameters.

### Overfitting

A model can perform very well on its training data but perform poorly on new data if it learns the training examples too closely. This is known as overfitting. IBM identifies overfitting as an important challenge in neural-network development.

### Bias and Data Quality

If training data contains errors, incomplete information, or undesirable biases, those issues can influence the resulting model. Therefore, responsible AI development requires attention to data quality, evaluation, fairness, privacy, and appropriate human oversight.

Understanding neural networks is valuable even for professionals who do not intend to become AI engineers.
